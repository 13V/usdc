## Link-in-bio structure

X only gives you one link, so point it at the app and let the app route. If you use
a link-hub, order it by intent:

1. **try the app (no signup)** → https://app.divvysol.com  ← the money link
2. **make a mochi meme** → https://app.divvysol.com/memes
3. **how it works / demo video** → link to the pinned thread
4. **iOS testflight beta** → your TestFlight invite link (gate with a reply/DM)
5. **terms / privacy** → https://app.divvysol.com/terms · /privacy

Keep #1 first and unmissable. Every "link?" reply gets the demo-mode link (see below).

## Launch-day checklist

### T-minus (day before)
- [ ] account bio, name (`divvy 🐸`), avatar (Mochi), header all set
- [ ] `demo.webm` + `mochi.webm` upload-tested on X (webm plays; if a client balks,
      keep an .mp4 fallback handy — same file, re-wrapped)
- [ ] ALT text written into every image/video (from THREAD.md)
- [ ] app.divvysol.com is up, "try it first" demo works on mobile + desktop
- [ ] og image unfurls correctly (paste the link into a DM to yourself to preview)
- [ ] the meme lab (/memes) loads and can post to X
- [ ] draft the whole thread in the composer; proof once more against the
      "would CT dunk on this?" list

### Launch (pick the window)
- [ ] **post the thread ~9–11am ET on a Tue/Wed/Thu.** avoids the late-night US
      degen lull and the friday check-out; catches both US morning and EU evening.
- [ ] pin the thread immediately
- [ ] first reply to your own thread = the try-it link again ("no signup, 30s:
      app.divvysol.com") so it rides at the top

### First hour (this is the whole game)
- [ ] be at the keyboard for 60 straight minutes. reply to **every** reply for the
      first hour — the algo weights early velocity + your own replies heavily
- [ ] every quote/reply that asks "link?" or "where do i try it?" → reply with the
      **demo-mode link**: `app.divvysol.com — tap "try it first," no signup 🐸`
- [ ] keep the reply-guy kit (in THREAD.md) open; answer custodial / chain / fees /
      ios / token from it, in your own voice, fast
- [ ] like + reply to the first ~20 people who engage; a couple of thoughtful
      replies > one more tweet
- [ ] drop `meme-settle-gm.png` or `mochi.webm` as a reply to a high-traction
      comment to keep the thread visually alive
- [ ] DO NOT argue with the "just use splitwise/venmo" reply — answer it once,
      cleanly (friends pay from a text with no app; settles instantly for ~$0.001),
      then let others pile on

### Rest of day
- [ ] quote-tweet your own thread ~4–5 hours later with a different angle (e.g. the
      "friends pay from a text" clip) to catch a second timezone
- [ ] retweet the best community memes / reactions (organic > any ad)
- [ ] check app telemetry: try_demo taps, demo → real conversions, any error spikes
- [ ] thank the early try-it users; ask what broke — bug reports on day one are gold

### Guardrails (say these the same way every time)
- non-custodial, your wallet / your keys
- dollars (usdc); $1 = $1
- **no token, no airdrop, no returns talk — ever.** "the app is the app; community
  stuff lives out here 🐸" is the full answer. don't improvise past it.
