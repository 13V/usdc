# Divvy — Gen-Z / crypto-native prompts (Flavor A, dialed in)

Direction locked: **dark + vibrant, USDC-blue anchor**, for young crypto-native
Gen-Z / millennials. Refined from audience + crypto-native-aesthetics research.

**What the research changed vs the first draft**
- **Money is set in MONO** (Space Mono / JetBrains Mono), big + tabular — the
  single strongest "crypto-native, not web2-fintech" signal (USDC/Circle's own
  system pairs display + mono-for-figures).
- **Voice = lowercase, dry, post-ironic** — kill money-awkwardness with humor, not
  hype. "settled. <1 second. <1 cent." No exclamation-hype, no wagmi/🚀/laser eyes.
- **USDC as "dollars, just faster"** — hide the chain (no gas/seed-phrase UI); show
  plain $. Money = trust, app = personality.
- **One accent + glow per screen**; the **kinetic gradient is reserved for the
  settle/success moment** (value moved), not a static background.
- **Mascot** (soft-animated coin/blob) + **emoji reactions as functional UI**.
- **"Money texture"** grounding (guilloché + a banknote security-strip neon),
  never fake-3D coins. Renamed primitives: a split = a **tab**, pay = **chip in**,
  done = **you're square ✨**. Every settle/summary is a **screenshot-ready card**.

## BASE (already included in every page prompt below)

> Design a fun, premium mobile screen (390×844) for **Divvy** — split bills with
> friends and settle instantly in **USDC on Solana**, shown as plain dollars
> ("dollars, just faster" — never market it as "crypto"). Audience: young,
> crypto-native Gen-Z / millennials. Vibe: **Phantom-meets-Cash-App** — dark,
> vibrant, emoji-native, a little irreverent, screenshot-worthy. The whole point
> is killing money-awkwardness between friends: exact amounts always visible, and
> settling up is the satisfying part. NOT corporate fintech, NOT a generic
> dark-card list, NOT 2021 degen cosplay.
>
> **LOOK & FEEL**
> - **Dark canvas** (base `#0B1622`, cards `#13212E`). **One** confident accent +
>   soft glow per screen. **USDC blue `#2775CA` is the anchor**, with lively
>   complements mint `#3DE8C7`, coral `#FF6B5E`, and sunshine `#FFC65C` used
>   sparingly for per-group identity + celebration. Resist rainbow-everything.
> - **Money is the hero, in a distinctive MONO** (`Space Mono` / `JetBrains
>   Mono`), big and tabular, decimals shown (`$165.00`), the `$`/decimals a touch
>   lighter. Headlines in a characterful display (`Clash Display` / `General
>   Sans`); UI in `General Sans`. No Inter, no one-font system.
> - A **kinetic two-color gradient** (USDC-blue→mint, Solana-style) is reserved for
>   **motion / success** (the settle confirmation, value-moved) — never a static
>   full-bleed background.
> - **Emoji + stickers as a first-class data layer:** every person and expense has
>   one; you react to payments (paid 🫡, still owe 👀, 💀). Functional, not decoration.
> - A soft-animated **mascot** — a friendly USDC-blue coin/blob — that reacts at the
>   settle moment. Ease-based motion (Phantom-style), never cheap bounce.
> - Subtle **"money texture"**: faint guilloché currency-engraving lines + a thin
>   neon "security-strip" accent (like a banknote's UV strip). Premium, thematically
>   money — NOT fake-3D coins.
> - **Voice: lowercase, dry, post-ironic, confident.** "you owe maya $14. don't be
>   weird about it." "settled. <1 second. <1 cent." "you're square ✨." Funny, not
>   naggy. Renamed primitives: a split = a **tab**, paying = **chip in**, done =
>   **square**.
> - Rounded shapes (cards 20–24px), chunky pill buttons, generous air. Bottom tab
>   bar (Home · Groups · ＋ · Activity · You), ease-based active state. Make every
>   settle/summary a **screenshot-ready share card**.
>
> **AVOID:** laser eyes, "wagmi/gm", 🚀/"to the moon", diamond hands; flat
> web3-purple; fake-3D/spinning coins; static rainbow-mesh backgrounds;
> hexagon/circuit-board/blockchain motifs; matrix techno type; seed-phrase / gas /
> network-fee UI up front; trading candlesticks; celebrity-shill FOMO; identical
> grey cards stacked evenly; tiny low-contrast numerals; Inter/one-font; cheap
> springy bounce.
